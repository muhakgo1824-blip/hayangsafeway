공공데이터 연동 설정

data.go.kr 에서 무료로 받은 인증키를 넣으면 실시간 대기질과 버스 도착정보가 표시됩니다. 키는 이 기기에만 저장되며 어디로도 전송되지 않습니다.

공공데이터포털 → “한국환경공단_에어코리아_대기오염정보” 활용신청
공공데이터포털 → “국토교통부_(TAGO)_버스도착정보” 활용신청
위 지점 버튼을 누르면 그 좌표 반경 500m 안의 정류소를 찾습니다. 결과를 누르면 자동으로 입력됩니다.
형식: 도시코드 / 정류소ID / 이름  (경산시 도시코드는 37050)
브라우저 직접 호출이 막히면 프록시 주소가 필요합니다
연결이 안 되는 이유
날씨는 Open-Meteo에서, 지도는 OpenStreetMap에서 받아옵니다. 둘 다 파일을 그냥 열어도(file://) 인터넷만 되면 작동합니다. 연결이 안 될 때 흔한 원인은 이렇습니다.
  • 인터넷이 끊김 — 와이파이·데이터를 확인해 주세요
  • 학교·공공 네트워크 차단 — 외부 API를 막는 경우가 있습니다. 휴대폰 핫스팟으로 열어보면 바로 구분됩니다
  • 광고 차단 확장 프로그램 — 외부 요청을 막기도 합니다. 잠시 꺼보세요
  • 서버 점검 — 잠시 뒤 새로고침(↻)을 눌러보세요
연결되면 제목 옆이 ● 실시간으로 바뀌고, 지도도 실제 지도로 나옵니다.

연결이 안 되는 동안에도 앱은 저장된 기상청 예보와 실제 좌표로 그린 약식 지도로 계속 작동합니다. 예측 값은 그대로 계산돼요.
